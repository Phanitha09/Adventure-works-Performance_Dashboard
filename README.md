# Adventure-works-Performance_Dashboard

This project helped me strengthen my skills in data cleaning, transformation, business analysis, and dashboard creation using advanced Excel features and Power Query.

**Project Overview**

Built an interactive sales dashboard to analyze:

• Sales Performance
• Production Cost
• Profitability
• Product Performance
• Quarterly & Monthly Trends
• KPI Metrics

The dashboard provides business insights that help understand revenue growth, cost distribution, and top-performing products.

**Tool Used**

Microsoft Excel - Power Query, Pivot Tables, Pivot Charts, Slicers

**Key Features**
- Sales & Profit Analysis
- Year-wise and Month-wise Trends
- KPI Metrics
- Product Performance Analysis
- Interactive Dashboard

**Dataset Used**

Adventure Works Sales Dataset including:
- FactInternetSales
- FactInternetSalesNew
- DimProduct
- DimCustomer
- DimDate
- DimSalesTerritory
- DimProductCategory
- DimProductSubCategory

**Key Steps Performed**

✅ Appended and cleaned datasets

✅ Handled null values and Merged Product & Customer tables

✅ Building relationships between sales, product, and customer data

✅ Creating calculated metrics like Sales Amount, Production Cost, and Profit

✅ Built Date hierarchy (Year, Month, Quarter, Financial Month)

✅ Analyzing monthly, quarterly, and yearly sales trends

✅ Designed interactive charts and dashboard visuals

**Key Insights**

📈 Total Sales crossed 29M+

📊 Q4 recorded the highest sales contribution

🏆 Road-150 series products emerged as top-performing products

💰 Strong profit margins observed across high-selling categories

📅 Year-wise sales showed continuous business growth trend
