# Adventure-works-Performance_Dashboard
Interactive Sales Analytics Dashboard built using Excel and Power Query.

**Tool Used**

Microsoft Excel - Power Query, Pivot Tables, Pivot Charts, Slicers

**Key Features**
- Sales & Profit Analysis
- Year-wise and Month-wise Trends
- KPI Metrics
- Product Performance Analysis
- Interactive Dashboard

**Dataset Used**

Adventure Works Sales Dataset including:
- FactInternetSales
- FactInternetSalesNew
- DimProduct
- DimCustomer
- DimDate
- DimSalesTerritory
- DimProductCategory
- DimProductSubCategory

**Key Steps Performed**

✅ Appended and cleaned datasets
✅ Handled null values and transformed data
✅ Merged Product & Customer tables
✅ Created calculated fields for Sales, Cost, and Profit
✅ Built Date hierarchy (Year, Month, Quarter, Financial Month)
✅ Designed interactive charts and dashboard visuals

**Key Insights**
📈 Total Sales crossed 29M+
📊 Q4 recorded the highest sales contribution
🏆 Road-150 series products emerged as top-performing products
💰 Strong profit margins observed across high-selling categories
📅 Year-wise sales showed continuous business growth trend

Data Cleaning, Data Transformation, Dashboard Design, Business Analytics
